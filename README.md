# koe2-supporter

[koe-koe.com](https://koe-koe.com/) を便利に使うための Chrome 拡張機能。

---

## インストール

1. [Releases](https://github.com/otmotm77/koe2-supporter/releases) から ZIP をダウンロードし展開する
2. Chrome で `chrome://extensions/` を開く
3. 右上の **デベロッパーモード** をオンにする
4. **「パッケージ化されていない拡張機能を読み込む」** をクリック
5. `koe2-supporter` フォルダを選択
6. ツールバーにアイコンが表示されれば完了

## 機能一覧

### ページ上の機能

#### ♥ FAV お気に入りボタン
- 全ページのユーザー名の前に `♥ FAV` ボタンを表示
- クリックでお気に入り登録／解除（登録済みは赤、未登録はグレー）
- 通常投稿・LIVE アーカイブを別々に管理
- トリップ（◆◇）が付くユーザーは別エントリとして管理

#### カード識別色（一覧・検索ページ）
| 表示 | 意味 |
|------|------|
| 薄青背景 | DL 済み |
| グレー背景（中） | 再生済み（未 DL） |
| グレー背景（濃） | ブラックリストユーザーの投稿 |
| オレンジ左ボーダー | お気に入りユーザーの投稿 |
| 緑左ボーダー | LIVE お気に入りユーザーの投稿 |
| `✓ DL済` バッジ | DL 済みの目印 |

#### フィルタバー（一覧・検索ページ上部）
- **♥ / DL / ▶** それぞれに **未指定・済・未** を組み合わせた AND フィルタ
- **🚫** ブラックリストユーザーを **含む / 除外**（デフォルト：除外）
- **WOMAN / MAN / COUPLE** アイコンで性別ごとの表示／非表示をトグル（デフォルト：全表示）
- × ボタンで全解除（🚫 は除外、性別は全表示に戻る）
- 同タブ内のページ移動をまたいで状態を保持

#### 🚫 ブラックリストボタン（詳細ページ）
- `detail.php` / `archive_detail.php` のダウンロードボタン横に表示
- `🚫ユーザをブラックリストに追加` / `🚫ユーザをブラックリストから削除` でトグル
- 登録済みユーザーの投稿は一覧でグレー背景になり、フィルタバーで除外可能

#### ⬇ ダウンロードボタン（詳細ページ）
- `detail.php`（通常投稿）と `archive_detail.php`（LIVE アーカイブ）に表示
- 設定フォルダへ自動保存
- ファイル名形式：
  - 通常：`[ユーザ名][ID][YYYYMMDD]タイトル.mp3`
  - LIVE：`[ユーザ名][l_ID][YYYYMMDD]配信.mp3`
- DL 済みはボタンが「✓ ダウンロード済み」に変化

#### ▶ 再生済みバッジ（詳細ページ）
- 再生開始で「▶ 再生済み」バッジを表示
- × クリアボタンで解除（一覧のグレー背景も解除）

### ポップアップの機能

#### ♥USER タブ
- 登録済み通常ユーザーの一覧
- 名前クリックで投稿一覧へ、× で削除
- 性別バッジ表示（ピンク：女性 / 青：男性 / ティール：カップル）

#### ♥LIVE タブ
- 登録済み LIVE アーカイブユーザーの一覧
- 名前クリックでアーカイブ検索へ

#### 🚫BL タブ
- ブラックリスト登録ユーザーの一覧（通常・LIVE 混在、USER / LIVE ラベルで区別）
- 名前クリックで検索ページへ、× で削除
- ブラックリストユーザーはフィルタバーでデフォルト除外される

#### 設定タブ
- **DL フォルダ名**：ダウンロード先サブフォルダ名（デフォルト: `koe2`）
  - 実際の保存先：`Downloads/koe2/`
- **DB ファイル更新＆リネーム**：
  - ブラウザの通常ダウンロードで保存された数字名ファイル（例: `12345.mp3`）を `[ユーザ名][ID][日付]タイトル.mp3` 形式に**一括リネーム**
  - LIVE アーカイブファイル（`live_012345.mp3`）にも対応
  - フォルダを選択するだけで対象を自動検出し、プレビュー確認後に実行
  - リネーム済みファイルを検出して DL 済みステータスを自動復元（再インストール後のデータ復旧にも有効）
  - ページ情報の取得は **1 件あたり 300ms のウェイトを設けてサーバー負荷を軽減**
  - 未取得件数が 50 件超の場合は処理前に件数・所要時間を表示して確認
- **エクスポート / インポート**：
  - お気に入り・DL 履歴・再生履歴・設定を JSON で保存・復元
  - 拡張機能の再インストール後のデータ復元に使用

## 対応ページ

| URL | 機能 |
|-----|------|
| `detail.php?n=` | DL ボタン・再生バッジ・ハート |
| `archive_detail.php?n=` | LIVE DL ボタン・再生バッジ・ハート |
| `search.php` | カード識別色・フィルタ・ハート |
| `archive_list.php` | カード識別色・フィルタ・ハート |
| `archive_search.php` | カード識別色・フィルタ・ハート |
| `post_users.php` | ハート |
| `live_top.php` | ハート |
| トップページ | カード識別色・ハート |

## ファイル構成

```
koe2-supporter/
├── manifest.json
├── background.js          # ダウンロード処理・ページ情報取得
├── content/
│   ├── audio_page.js      # 詳細ページ用（DL・再生トラッキング）
│   └── user_page.js       # 全ページ用（ハート・カード色・フィルタ）
├── popup/
│   ├── popup.html
│   └── popup.js
└── icons/
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```
